What Does a Shell Do?

At its core, a shell is a command-line interpreter. Its primary job is to accept commands from the user and launch the corresponding programs (such as ls, cp, or custom apps).

Built-in vs. External Commands

Built-in Commands: These are executed directly by the shell process itself. Examples include cd (change directory) and exit.

External Commands: These are standalone executable files stored on your system (typically in directories like /bin or /usr/bin). When you run ls, the shell locates and executes the binary file located at /bin/ls.

I/O Redirection in Unix

Unix shells allow you to redirect standard output from a command to a destination other than the terminal display.

The Output Redirection Operator (>)

The > operator takes the output generated by a command and writes it directly into a file.

Example:

ls > list.txt

In this example, the output of the ls command is redirected and saved into list.txt instead of being displayed on the screen.
