rm

Its removing the files thats it example we have a file name "file.txt" to remove it we do: 

rm file.txt

Choices:

-r: is used to remove directories and their contents example:

we have a dir name "test" and it has 

test/
    ├── test1
    |── test2
        └── test3

whe we try remove it normal it will give is error but with this choose we can remove it in only one line command:

rm -r test/

And hats it.
